# CO2 Prediction Article and Supplement: Code and Data

This repository contains the executed analysis notebook and input dataset for the article and supplementary analyses.

## Files
- `Nimra_Tariq_Article_Supplement_Code.ipynb` — analysis notebook
- `south asia co2 dataset.csv` — input dataset

## Run
Keep both files in the same folder. Open the notebook in Google Colab or Jupyter and run the cells in order.
